# Physik – Materialien für den Unterricht

Willkommen in unserer Physik-Materialsammlung!

Hier findet ihr nach und nach Lernblätter, Übungsaufgaben und weitere Materialien aus unserem Physikunterricht. Sie helfen euch dabei, Unterrichtsinhalte nachzulesen, zu wiederholen und selbstständig zu üben.
